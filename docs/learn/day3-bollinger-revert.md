# Day 3：从 `rsi_revert` 到 `bollinger_revert`

## 目标

Day 2 证明了 `rsi_revert` 的核心问题：只靠 RSI 超卖信号，交易太少，也分不清震荡超跌和趋势下跌。

Day 3 学习如何在不引入复杂模型的前提下，把这个失败原因拆开，并改成一个更完整的均值回归策略：`bollinger_revert`。

## 为什么要改

`rsi_revert` 的入场依据太单薄：

```text
RSI 很低
价格在长期均线上方
```

但 RSI 低只说明最近跌得多，不能说明价格是否真的偏离了正常波动区间，也不能说明当前行情是不是震荡。

所以优化方向不是继续调 RSI 参数，而是增加能回答这些问题的过滤：

- 价格是否真的跌到区间下沿？
- 当前是不是震荡环境？
- 是否正在明显下跌趋势中？

## `bollinger_revert` 增加了什么

`bollinger_revert` 仍然是均值回归策略，但它比 `rsi_revert` 多了三个判断。

第一，用 Bollinger 下轨确认价格偏离。

```text
价格 <= Bollinger 下轨
```

这说明价格不只是 RSI 低，而是真的跌到了近期波动区间的下沿。

第二，用 ADX 过滤趋势。

```text
ADX <= max_adx
```

ADX 低时，市场更可能是震荡。均值回归策略应该尽量在震荡里做，而不是在强趋势里做。

第三，用长期 EMA 避免强下跌。

```text
价格 > 长期 EMA
或者长期 EMA 没有向下
```

这一步是为了避免在明显下跌趋势里抄底。

## 优化后的完整规则

入场条件：

- ADX 不高，说明市场更偏震荡。
- 价格没有处在明显强下跌趋势。
- 价格触碰 Bollinger 下轨。
- RSI 处于超卖区间。
- 风控允许开仓。

出场条件：

- 价格回到 Bollinger 中轨。
- 或 RSI 回到中性区间。
- 或触发通用风控，例如 ATR 止损、时间止损、冷却和最大回撤控制。

相比 `rsi_revert`，这个策略更完整，因为它不只问“有没有超卖”，还问“这个超卖是否发生在适合均值回归的环境里”。

## 已有回测结果

已有记录里，`bollinger_revert` 在 `ETH/USDT 1h`、`2024-01-01 ~ 2025-01-01` 的结果是：

| 指标 | 结果 |
| --- | ---: |
| 收益 | `1.58%` |
| Sharpe | `0.45` |
| 最大回撤 | `-3.64%` |
| 交易次数 | `20` |
| 胜率 | `60.00%` |
| Profit Factor | `1.26` |

这个结果比 `rsi_revert` 更有研究价值：

- 交易次数从很少提升到 `20` 笔。
- 胜率较高。
- 回撤仍然较低。
- Profit Factor 大于 `1.0`。

但它仍然不是主策略：

- 收益只有 `1.58%`。
- 交易次数仍然偏少。
- 当时还没有年度、季度、成本压力和多交易对验证。
- 它更适合作为组合里的震荡补充模块。

更大的样本外搜索里，`bollinger_revert` 的最好候选样本外年化约 `2.10%`，Sharpe `0.62`，最大回撤 `-1.04%`，但只有 `5` 笔交易。这个样本太少，不能证明稳定。

## 多交易对验证

2026-05-27 又补做了一组跨交易对验证。口径是：

- 策略：`bollinger_revert` 默认参数。
- 周期：`1h`。
- 区间：`2023-01-01 ~ 2026-05-14`。
- 工具：`main.py evaluate`，包含全区间、年度、季度和成本压力测试。
- 交易成本：默认 `commission=0.001`、`slippage=0.0005`。

| `SOL/USDT` | `-22.82%` | `457.86%` | `-1.99` | `-25.36%` | 51 | `0.39` |

`BTC/USDT` 也跑了同口径评估，但结果是 `0` 笔交易，不能用于判断策略。原因是当前回测资金是 `10000`，Backtesting.py 默认不支持碎片化交易，BTC 价格高于初始资金时无法开仓。

这组验证把结论从“可能适合作为震荡补充模块”改成了更保守的判断：`bollinger_revert` 不是一个好的独立策略。

主要问题是：

- 多数交易对全区间亏损，Sharpe 全部为负。
- `BNB`、`SOL`、`XRP` 的 Profit Factor 都明显低于 `1.0`。
- `ADA` 的 Profit Factor 虽然是 `1.10`，但全区间仍亏 `-6.51%`，说明盈利交易不足以覆盖亏损、成本和不利阶段。
- `DOGE` 接近持平，但 Sharpe 仍为负，Profit Factor 也低于 `1.0`。
- 年度和季度分段不稳定，收益集中在少数片段，不能证明策略假设可以跨市场持续成立。
- 成本压力下表现继续恶化，说明策略边际很薄。

## 为什么会这样

`bollinger_revert` 的核心假设是：价格触碰 Bollinger 下轨后，会在低趋势强度环境里回到中轨或 RSI 中性区间。

这个假设在单个震荡阶段可能有效，但跨交易对后暴露出几个问题。

第一，低 ADX 不等于没有趋势风险。

ADX 低只能说明最近趋势强度不明显，不能保证下跌已经结束。很多加密货币会先经历缓慢走弱，再突然加速下跌。此时策略看到的是“低 ADX + 触碰下轨 + RSI 超卖”，但真实市场可能是下跌趋势刚开始。

第二，Bollinger 下轨不是可靠支撑。

Bollinger 下轨只是近期波动区间的统计边界，不是订单流支撑位。强势资产回调时触碰下轨可能反弹，弱势资产触碰下轨后可能继续贴着下轨下跌。跨资产结果里，`SOL`、`XRP` 这类高波动交易对的亏损尤其明显，说明“偏离后回归”的假设不稳定。

第三，均值回归收益空间太薄，交易成本影响大。

这个策略通常吃的是从下轨到中轨、或 RSI 回到中性的一小段反弹。单笔平均收益不大，而每笔都要支付手续费和滑点。只要胜率下降一点，或反弹幅度变小，Profit Factor 就会掉到 `1.0` 以下。

第四，过滤条件减少了错误交易，也减少了有效样本。

ADX、长期 EMA、ATR 风控让策略更谨慎，但也让交易次数偏少。样本少时，少数亏损季度就会主导长期结果；样本外搜索里最好候选也只有 `5` 笔交易，不能证明稳定。

第五，策略没有处理市场状态切换。

它只做震荡均值回归，不参与趋势行情。加密货币的大部分收益来自少数强趋势阶段；当市场上涨时，它经常空仓，当市场下跌时又可能尝试接反弹。结果就是既吃不到大趋势，又容易在弱势反弹里亏损。

## 今天学到什么

第一，优化必须对应失败原因。

`rsi_revert` 的问题是只看 RSI，所以 `bollinger_revert` 增加的是价格区间、趋势强度和下跌过滤，而不是盲目扩大参数。

第二，过滤条件必须服务于策略假设。

均值回归的假设是“价格偏离后会回归”。所以 Bollinger 下轨、ADX、长期 EMA 都是在帮助判断这个假设是否成立。

第三，策略变复杂一点可以，但每一层都要有明确理由。

`bollinger_revert` 没有引入机器学习，也没有做复杂组合，只是补齐了 RSI 策略缺失的环境判断。

第四，改进后仍然要诚实看结果。

`bollinger_revert` 比 `rsi_revert` 更完整，但跨交易对验证后表现不好。它是一个更好的教学案例，不是一个可以直接实盘的策略。

## Day 3 结论

`bollinger_revert` 的价值在于说明：策略优化不是追求更多指标，而是给原始策略补上缺失的判断；同时也说明，一个逻辑更完整的策略，不代表它一定有稳定正期望。

从 `rsi_revert` 到 `bollinger_revert`，真正学到的是：

> RSI 只能告诉你“跌得多不多”，不能告诉你“该不该买”。一个可研究的均值回归策略，必须同时判断价格偏离、市场状态和下跌风险。
