# Day 3：从 `rsi_revert` 到 `bollinger_revert`

## 目标

Day 2 证明了 `rsi_revert` 的核心问题：只靠 RSI 超卖信号，交易太少，也分不清震荡超跌和趋势下跌。

Day 3 学习如何在不引入复杂模型的前提下，把这个失败原因拆开，并改成一个更完整的均值回归策略：`bollinger_revert`。

## 为什么要改

`rsi_revert` 的入场依据太单薄：

```text
RSI 很低
价格在长期均线上方
```

但 RSI 低只说明最近跌得多，不能说明价格是否真的偏离了正常波动区间，也不能说明当前行情是不是震荡。

所以优化方向不是继续调 RSI 参数，而是增加能回答这些问题的过滤：

- 价格是否真的跌到区间下沿？
- 当前是不是震荡环境？
- 是否正在明显下跌趋势中？

## `bollinger_revert` 增加了什么

`bollinger_revert` 仍然是均值回归策略，但它比 `rsi_revert` 多了三个判断。

第一，用 Bollinger 下轨确认价格偏离。

```text
价格 <= Bollinger 下轨
```

这说明价格不只是 RSI 低，而是真的跌到了近期波动区间的下沿。

第二，用 ADX 过滤趋势。

```text
ADX <= max_adx
```

ADX 低时，市场更可能是震荡。均值回归策略应该尽量在震荡里做，而不是在强趋势里做。

第三，用长期 EMA 避免强下跌。

```text
价格 > 长期 EMA
或者长期 EMA 没有向下
```

这一步是为了避免在明显下跌趋势里抄底。

## 优化后的完整规则

入场条件：

- ADX 不高，说明市场更偏震荡。
- 价格没有处在明显强下跌趋势。
- 价格触碰 Bollinger 下轨。
- RSI 处于超卖区间。
- 风控允许开仓。

出场条件：

- 价格回到 Bollinger 中轨。
- 或 RSI 回到中性区间。
- 或触发通用风控，例如 ATR 止损、时间止损、冷却和最大回撤控制。

相比 `rsi_revert`，这个策略更完整，因为它不只问“有没有超卖”，还问“这个超卖是否发生在适合均值回归的环境里”。

## 已有回测结果

已有记录里，`bollinger_revert` 在 `ETH/USDT 1h`、`2024-01-01 ~ 2025-01-01` 的结果是：

| 指标 | 结果 |
| --- | ---: |
| 收益 | `1.58%` |
| Sharpe | `0.45` |
| 最大回撤 | `-3.64%` |
| 交易次数 | `20` |
| 胜率 | `60.00%` |
| Profit Factor | `1.26` |

这个结果比 `rsi_revert` 更有研究价值：

- 交易次数从很少提升到 `20` 笔。
- 胜率较高。
- 回撤仍然较低。
- Profit Factor 大于 `1.0`。

但它仍然不是主策略：

- 收益只有 `1.58%`。
- 交易次数仍然偏少。
- 还需要年度、季度和成本压力测试。
- 它更适合作为组合里的震荡补充模块。

更大的样本外搜索里，`bollinger_revert` 的最好候选样本外年化约 `2.10%`，Sharpe `0.62`，最大回撤 `-1.04%`，但只有 `5` 笔交易。这个样本太少，不能证明稳定。

## 今天学到什么

第一，优化必须对应失败原因。

`rsi_revert` 的问题是只看 RSI，所以 `bollinger_revert` 增加的是价格区间、趋势强度和下跌过滤，而不是盲目扩大参数。

第二，过滤条件必须服务于策略假设。

均值回归的假设是“价格偏离后会回归”。所以 Bollinger 下轨、ADX、长期 EMA 都是在帮助判断这个假设是否成立。

第三，策略变复杂一点可以，但每一层都要有明确理由。

`bollinger_revert` 没有引入机器学习，也没有做复杂组合，只是补齐了 RSI 策略缺失的环境判断。

第四，改进后仍然要诚实看结果。

`bollinger_revert` 比 `rsi_revert` 好，但收益仍然低，交易样本仍然不够大。它是一个更好的教学案例，不是一个可以直接实盘的策略。

## Day 3 结论

`bollinger_revert` 的价值在于说明：策略优化不是追求更多指标，而是给原始策略补上缺失的判断。

从 `rsi_revert` 到 `bollinger_revert`，真正学到的是：

> RSI 只能告诉你“跌得多不多”，不能告诉你“该不该买”。一个可研究的均值回归策略，必须同时判断价格偏离、市场状态和下跌风险。
