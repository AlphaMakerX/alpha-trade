# 学习计划 Overview

## 目标

近期目标：系统学习并验证 `10` 个基础交易策略，理解每个策略的盈利来源、适用行情、失败原因和回测验证方法。

重点不是背指标，而是学会判断：

- 策略赚的是什么钱。
- 策略适合什么行情。
- 策略为什么会亏。
- 回测结果是否有足够交易样本。
- 成本和分段验证后是否还能成立。

## 学习节奏

每个策略按同一套流程学习：

1. 先讲清楚交易逻辑。
2. 看项目里的实现方式。
3. 跑不同交易对和不同区间的回测。
4. 总结收益、回撤、交易次数和失败原因。
5. 判断它适合作为主策略、辅助模块，还是应该放弃。
