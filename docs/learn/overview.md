# 学习计划 Overview

## 最终目标

在 ETH/USDT 市场上，用一套能解释、能回测、能控制风险的系统化方法稳定赚钱。

不是预测涨跌，而是建立一个可重复的流程：**找到收益来源 → 做成最小策略 → 严格验证 → 控制风险 → 实盘执行 → 持续迭代**。

## 你的抓手（唯一主线）

一切学习都挂在一条主线上：

> **可回测验证的策略闭环。**

判断「某个知识/方法该不该现在学」的标准只有一句话：

> 它能不能帮我在 ETH/USDT 上**构建、验证、控制风险或执行**一个策略？

- 能 → 学，并且立刻在项目的回测引擎里用一次。
- 不能 → 先记下来，不要现在学。

这条主线避免两个最大的坑：一是收藏一堆指标和名词却不会用；二是上来就堆机器学习和复杂组合，最后说不清到底为什么赚钱。

## 不要做的事

- 不要先学一堆指标再想怎么用。指标只是信号，不是收益来源。
- 不要一开始就上机器学习、深度学习、复杂多因子。
- 不要用没有止损和仓位管理的回测结果说服自己。
- 不要因为一次漂亮回测就重仓，先怀疑是不是过拟合。
- 不要跳过「成本压力测试」。手续费和滑点能杀死大多数边际薄的策略。

## 学习阶段路线图

每个阶段都有明确的「完成判据」，达成才进入下一阶段。前期阶段可以并行推进。

### 阶段 0：认知与心法（已基本完成）

- 内容：策略为什么赚钱、适用环境、风险控制五要素、正确研究顺序。
- 对应：Day 1。
- 完成判据：任何一个策略想法，你都能先回答「赚什么钱 / 适合什么行情 / 什么时候会亏」。

### 阶段 1：市场与交易基础

- 内容：ETH/USDT 的现货 vs 永续合约、手续费结构、资金费率（funding rate）、滑点与盘口深度、做市/吃单、杠杆与强平机制。
- 为什么重要：这些直接决定回测里的成本假设是否真实。成本错了，所有结论都错。
- 完成判据：能写清楚你回测里用的手续费、滑点、是现货还是合约，并说明为什么这样设。

### 阶段 2：策略与收益来源（进行中，核心阶段）

- 内容：系统学习并验证 10 个基础策略，理解每个策略的盈利来源、适用行情、失败原因和回测验证方法。
- 重点不是背指标，而是学会判断：
  - 策略赚的是什么钱。
  - 策略适合什么行情。
  - 策略为什么会亏。
  - 回测样本是否足够。
  - 成本和分段验证后是否还成立。
- 完成判据：10 个策略每个都有一句结论「在什么情况下可能赚钱，在什么情况下不该用」，并筛出 1–2 个有实盘研究价值的。

### 阶段 3：回测与统计验证方法

- 内容：过拟合（overfitting）、样本内/样本外、walk-forward 验证、多重检验偏差（多次调参的代价）、Profit Factor / Sharpe / 最大回撤 / 交易次数等指标的真正含义、前视偏差（look-ahead bias）与幸存者偏差。
- 为什么重要：这是把「跑通」和「可实盘」区分开的能力，决定你不会被自己骗。
- 完成判据：能对任意一个回测结果说出「这里可能过拟合 / 样本不够 / 有偏差」的具体理由。

### 阶段 4：风险与仓位管理

- 内容：仓位 sizing、固定比例 vs 凯利（Kelly）及其缩水使用、最大回撤承受度、风险敞口、爆仓概率（risk of ruin）、相关性与杠杆的真实风险。
- 为什么重要：长期能不能活下来，由风险管理决定，而不是由信号决定。
- 完成判据：每个候选策略都有明确的「单笔最多亏账户多少」和「整体回撤上限」规则，并在回测里执行。

### 阶段 5：组合与行情切换

- 内容：多策略组合、趋势/震荡 regime 切换、相关性分散、现金/空仓防守、何时该不交易。
- 为什么重要：单一策略总有失效阶段，组合是把收益曲线变平滑的关键。
- 完成判据：能把至少 2 个低相关策略组合，回测出比单策略更稳的收益曲线。

### 阶段 6：实盘与执行

- 内容：paper trading（模拟盘）、实盘滑点与延迟、下单方式、交易所 API、监控与告警、实盘与回测的差异归因。
- 为什么重要：回测赚钱不等于实盘赚钱，执行细节会吃掉边际。
- 完成判据：用小资金或模拟盘跑通一个完整策略，并能解释实盘与回测的差异。

### 阶段 7：持续迭代

- 内容：建立「发现失效 → 归因 → 小改动 → 重新验证」的常态循环，记录每次改动的理由和结果。
- 完成判据：形成稳定的迭代节奏，每次改动都能追溯到一个具体的失败原因。

## 每个策略的学习流程（阶段 2 的标准动作）

1. 先讲清楚交易逻辑。
2. 看项目里的实现方式。
3. 跑不同交易对和不同区间的回测。
4. 总结收益、回撤、交易次数和失败原因。
5. 判断它适合作为主策略、辅助模块，还是应该放弃。

## 学习原则

- 先证明策略**为什么应该赚钱**，再证明它**在数据上真的赚钱**，最后证明它**在成本和坏行情下还能活下来**。
- 每学一个知识点，立刻在回测里用一次，否则不算学会。
- 每学一个策略，都要形成一句结论：

  > 这个策略在什么情况下可能赚钱，在什么情况下不该用。
