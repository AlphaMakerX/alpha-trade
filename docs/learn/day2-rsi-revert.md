# Day 2：理解 `rsi_revert`

## 目标

今天只学习一个策略：`rsi_revert`。

目标不是优化它，而是先把它的交易模式、项目里的实现方式、回测结果和失败原因讲清楚。

## `rsi_revert` 是什么交易模式

`rsi_revert` 是一种均值回归策略。

它的核心想法是：

> 价格短期跌得太快，RSI 变得很低，说明市场可能短期卖过头了。这个时候买入，等价格反弹后卖出。

它不是追涨策略，也不是趋势策略。它买的是“超跌反弹”。

一个简化例子：

```text
价格原来在 100 附近震荡
突然连续下跌到 94
RSI 掉到 30 以下
策略认为：短期可能跌过头了
于是买入
如果价格反弹，或 RSI 回到较高位置，就卖出
```

这个模式适合震荡行情，不适合单边下跌行情。

## RSI 的含义

RSI 用来衡量最近一段时间上涨和下跌力量的相对强弱，常见范围是 `0 ~ 100`。

常见理解：

- RSI 高于 `70`：可能短期涨太多，偏超买。
- RSI 低于 `30`：可能短期跌太多，偏超卖。
- RSI 接近 `50`：上涨和下跌力量相对均衡。

经典公式是：

```text
RSI = 100 - 100 / (1 + RS)
RS = 平均上涨幅度 / 平均下跌幅度
```

如果最近上涨多、下跌少，RSI 会高。  
如果最近下跌多、上涨少，RSI 会低。

## 项目里的 `rsi_revert` 怎么交易

项目里的策略代码在：

```text
strategies/mean_revert/rsi_revert.py
```

默认参数：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `rsi_period` | `14` | RSI 计算周期 |
| `oversold` | `25` | RSI 低于该值才认为超卖 |
| `overbought` | `75` | RSI 高于该值时平仓 |
| `trend_period` | `200` | 长期均线周期 |
| `atr_period` | `20` | ATR 止损计算周期 |
| `atr_multiplier` | `1.5` | ATR 止损倍数 |

入场规则：

```text
RSI < oversold
并且价格 > 200 周期均线
并且风控允许开仓
```

出场规则：

```text
RSI > overbought
或者触发通用风控
```

所以它实际买的是：

> 上涨趋势里的短期超跌反弹。

它不是在所有 RSI 低的时候都买。价格必须还在长期均线上方。

## 这个策略为什么容易不交易

它的条件其实很严格：

- RSI 要低到 `25` 以下。
- 价格还要在长期均线上方。
- 风控不能处在冷却或限制状态。

这三个条件同时满足的机会不多。

所以它经常出现一种情况：

```text
策略看起来很谨慎
回撤很小
但长期没有交易
收益也很低
```

这就是 `rsi_revert` 的核心问题：不是爆亏，而是没有足够交易样本。

## 今天学到什么

第一，低回撤不等于好策略。

`rsi_revert` 经常回撤很低，是因为它几乎不交易。空仓本身不会亏钱，但也不能证明策略有赚钱能力。

第二，交易次数太少时，指标没有意义。

1 笔、2 笔、7 笔交易都不能证明策略稳定。Profit Factor、胜率、Sharpe 在这种样本下都容易误导。

第三，单纯 RSI 超卖信号不够。

RSI 低只说明最近跌得多，但不能区分：

- 震荡区间里的短期超跌。
- 下跌趋势里的持续走弱。

这就是 RSI 均值回归策略最核心的风险。

第四，趋势过滤会降低接刀风险，但也会让策略更少交易。

项目里的 `rsi_revert` 要求价格在长期均线上方，这能避免一部分下跌趋势抄底，但代价是触发次数非常少。

第五，参数搜索不能解决结构性问题。

如果策略逻辑本身太难触发，扩大参数网格只会找到一些样本很少的偶然结果，不会变成稳定策略。

## Day 2 结论

`rsi_revert` 在当前项目里不是有效主策略。

它的主要失败原因不是大亏，而是：

> 条件太严格，跨交易对和跨区间都没有足够交易样本，资金长期闲置。

后续如果要继续做均值回归，不能只靠 RSI。需要补充“价格是否真的偏离区间”“当前是否处在震荡环境”“是否正在强下跌”等判断。
