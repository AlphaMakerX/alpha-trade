# Day 4：从均值回归到趋势持仓

## 目标

Day 3 证明了 `bollinger_revert` 的核心问题：逻辑比 `rsi_revert` 更完整，但跨交易对后仍然没有稳定正期望。

Day 4 不继续优化均值回归，而是学习另一类策略：趋势持仓。

今天要回答三个问题：

1. 为什么加密货币更值得研究趋势策略？
2. 为什么普通双均线不够？
3. 一个更完整的趋势持仓策略应该包含什么？

## 为什么转向趋势

均值回归赚的是短期修复的钱：

```text
价格跌多了
短期反弹
吃一段回归
```

这个模式的问题是收益空间通常不大，而且怕单边下跌。Day 3 的多交易对结果已经说明：Bollinger 下轨和低 ADX 不能保证价格会反弹。

趋势策略赚的是另一种钱：

```text
价格进入强趋势
趋势持续一段时间
少数大盈利单覆盖多数小亏损
```

加密货币经常出现右尾行情。很多交易对的大部分收益不是平均分布在每一天，而是集中在少数强趋势阶段。如果策略长期空仓，或者只做短线反弹，就容易错过主要收益来源。

所以 Day 4 的重点不是提高胜率，而是学习如何：

- 识别趋势已经形成。
- 在趋势中入场。
- 尽量拿住盈利单。
- 在趋势失效时退出。

## 双均线适不适合 Day 4

双均线可以学，但不适合作为主线。

最简单的双均线规则是：

```text
短均线上穿长均线，买入
短均线下穿长均线，卖出
```

它的优点是非常清楚：

- 容易理解。
- 参数少。
- 能表达趋势跟随思想。
- 适合作为趋势策略的入门对照组。

但它的问题也明显：

- 信号滞后，趋势走出一段后才入场。
- 震荡行情里容易反复金叉死叉。
- 出场也滞后，盈利回吐较多。
- 很难区分“刚开始的趋势”和“震荡里的噪音”。
- 单靠均线交叉，不能处理波动、突破和持仓管理。

项目里已经有 `ma_cross`，而且已有搜索结果显示它不是稳健答案：最好的样本外候选年化约 `11.80%`，但训练段为负，更像近期行情适配，不适合直接实盘。

所以 Day 4 可以把双均线当作对照组，但真正要学的是趋势持仓。

## Day 4 学习对象：`trend_holding_v3`

项目里已有一个趋势持仓原型：

```text
strategies/trend/trend_holding_v3.py
```

它不是简单金叉死叉，而是把趋势策略拆成四个问题。

第一，当前是否有趋势。

```text
价格 > 长期 EMA
并且长期 EMA 向上
```

这一步避免在长期下跌或无方向震荡里盲目做多。

第二，趋势中什么时候入场。

```text
价格突破 Donchian 高点
或者回踩 EMA 后重新站上
```

突破入场适合强趋势启动，回踩重站适合趋势中继。它比单纯均线金叉更接近真实交易问题：不是只问“均线有没有交叉”，而是问“价格有没有重新表现出趋势强度”。

### 什么是回踩重站

回踩重站的核心不是追高，而是在上涨趋势已经存在时，等价格短暂回落，再重新恢复强势。

在 `trend_holding_v3` 里，它对应的条件是：

```text
上一根收盘价 <= 短 EMA
当前价格 > 短 EMA
当前价格 > 上一根 K 线高点
```

用更直白的话说：

```text
价格原本处在上涨趋势里
短线回踩到短 EMA 附近
没有继续跌破趋势结构
下一根 K 线重新站上短 EMA
并且突破上一根 K 线高点
```

这说明卖压可能已经释放，买盘重新接回趋势。它买的不是“最低点”，而是“趋势回调后重新转强的确认点”。

举一个简化例子：

```text
长期趋势向上
短 EMA = 2500
上一根收盘 = 2480
上一根高点 = 2520
当前价格 = 2530
```

此时价格先回到短 EMA 下方或附近，随后又站回 `2500` 上方，并突破上一根高点 `2520`。这就是回踩重站。

它和突破入场的区别是：

- 突破入场：价格直接创一段时间新高，适合趋势刚加速。
- 回踩重站：价格已经有趋势，先回调，再重新走强，适合趋势中继。

回踩重站的优势是入场位置通常比追 Donchian 新高更低，不一定要在情绪最热的时候买。但它也有风险：如果所谓回踩其实是趋势反转的开始，重新站上短 EMA 可能只是一次假反弹，所以仍然需要长期 EMA、ATR 过滤和止损一起约束。

第三，当前波动是否适合交易。

```text
ATR 分位数不能太低
ATR 分位数也不能太高
```

波动太低时，突破可能没有延续；波动太高时，入场容易追在情绪极端位置。ATR 分位数过滤是为了避开这两种环境。

第四，趋势什么时候结束。

```text
跌破 Donchian 下轨
或者结构破坏
或者 ATR trailing stop 触发
```

趋势策略的关键不是每次都买在最低点，而是不要太早卖掉真正的大趋势。出场逻辑必须允许盈利单继续跑，同时在趋势破坏时退出。

## 完整规则

入场条件：

- 价格在长期 EMA 上方。
- 长期 EMA 向上。
- ATR 分位数在允许区间内。
- 价格突破前高，或回踩短 EMA 后重新站上。
- 风控允许开仓。

出场条件：

- 跌破 Donchian 下轨。
- 或价格跌破短 EMA 且长期 EMA 转弱。
- 或触发 ATR 跟踪止损。
- 或触发通用风控，例如最大回撤、冷却和持仓时间限制。

这个策略的假设是：

> 加密货币趋势一旦形成，可能持续足够久。策略可以接受多次小亏，但必须抓住少数大行情。

## 已有验证结果

已有记录里，`trend_holding_v3` 默认参数在 `ETH/USDT 1h`、`2023-01-01 ~ 2026-05-14` 的评估结果是：

| 指标 | 结果 |
| --- | ---: |
| 收益 | `15.24%` |
| Sharpe | `0.52` |
| 最大回撤 | `-7.00%` |
| 交易次数 | `202` |
| Profit Factor | `1.14` |

年度表现：

- `2023`、`2024`、`2025` 为正。
- `2026-01-01 ~ 2026-05-14` 为 `-3.47%`。

成本压力：

- `commission=0.10%`、`slippage=0.20%` 时，Profit Factor 约 `1.01`。
- `commission=0.20%` 场景下失效。

这个结果比 Day 3 的 `bollinger_revert` 更值得继续研究，因为：

- 交易次数足够，不是靠几笔样本撑结论。
- 全区间收益为正。
- 多个年度为正。
- 它的收益来源符合加密货币右尾行情特征。

但它仍然不能直接实盘：

- 收益边际还薄。
- 成本稍高就会失效。
- 2026 年阶段亏损。
- 高周期趋势过滤还没有补齐。
- 还没有完成更多交易对和周期的验证。

## 补充验证：放宽止损、拆分入场和 4H 过滤

2026-05-28 继续围绕 `ETH/USDT 1h` 做了几组验证。基础区间仍然是 `2023-01-01 ~ 2026-05-14`。

第一组实验是放宽 ATR 跟踪止损。

把 `trailing_atr_multiplier` 从 `2.0` 放宽到 `3.0` 后，结果变成：

| 指标 | `2.0` | `3.0` |
| --- | ---: | ---: |
| 收益 | `15.24%` | `18.77%` |
| Sharpe | `0.52` | `0.56` |
| 最大回撤 | `-7.00%` | `-8.75%` |
| 交易次数 | `202` | `169` |
| Profit Factor | `1.14` | `1.17` |
| 最长持仓 | `3 天 10 小时` | `5 天 10 小时` |

结论是：放宽跟踪止损后，策略更能拿住趋势，交易次数下降，收益和 Profit Factor 都提高；代价是最大回撤也变大。

第二组实验是拆分两种入场。

当前策略有两种入场：

- 突破入场：价格突破 Donchian 高点。
- 回踩重站：价格回踩短 EMA 后重新站上，并突破上一根 K 线高点。

在 `trailing_atr_multiplier=3.0` 且不加 4H 过滤时，结果如下：

| 入场方式 | 收益 | Sharpe | 最大回撤 | 交易次数 | Profit Factor |
| --- | ---: | ---: | ---: | ---: | ---: |
| 两种入场都开 | `18.77%` | `0.56` | `-8.75%` | `169` | `1.17` |
| 只突破入场 | `5.39%` | `0.26` | `-8.15%` | `95` | `1.12` |
| 只回踩重站 | `23.90%` | `0.80` | `-7.37%` | `100` | `1.46` |

结论是：在这组 ETH 回测里，回踩重站明显强于单独突破。突破入场单独使用时收益和质量都偏弱。

第三组实验是增加 4H 趋势过滤。

4H 过滤规则是：

```text
4H close > 4H EMA200
并且 4H EMA200 向上
```

开启 4H 过滤后，结果如下：

| 入场方式 | 收益 | Sharpe | 最大回撤 | 交易次数 | Profit Factor |
| --- | ---: | ---: | ---: | ---: | ---: |
| 两种入场 + 4H 过滤 | `22.36%` | `0.73` | `-10.58%` | `118` | `1.39` |
| 只突破 + 4H 过滤 | `8.85%` | `0.49` | `-6.86%` | `67` | `1.30` |
| 只回踩重站 + 4H 过滤 | `16.86%` | `0.66` | `-7.49%` | `66` | `1.59` |

这说明 4H 过滤有效，但它的作用不是简单提高收益，而是减少低质量交易、提高交易质量。

对“两种入场都开”的版本，4H 过滤带来的变化是：

```text
收益：18.77% -> 22.36%
交易次数：169 -> 118
Sharpe：0.56 -> 0.73
Profit Factor：1.17 -> 1.39
最大回撤：-8.75% -> -10.58%
```

对“只回踩重站”的版本，4H 过滤带来的变化是：

```text
收益：23.90% -> 16.86%
交易次数：100 -> 66
Profit Factor：1.46 -> 1.59
最大回撤：-7.37% -> -7.49%
```

所以当前 ETH 上有两个候选方向：

- 如果更看重收益：两种入场 + 4H 过滤。
- 如果更看重交易质量：只回踩重站 + 4H 过滤。

阶段性主候选是：

```text
trailing_atr_multiplier = 3.0
use_breakout_entry = true
use_pullback_entry = true
use_higher_timeframe_filter = true
```

它不是最终实盘版本，但比最初默认版本更值得进入多交易对验证。

## 补充验证：近期区间表现

为了检查策略是否只在较早行情有效，又额外跑了两个近期区间。

`2026-01-01 ~ 2026-05-14`，两种入场 + 4H 过滤：

| 指标 | 结果 |
| --- | ---: |
| 收益 | `-1.64%` |
| Buy & Hold | `-3.37%` |
| Sharpe | `-0.99` |
| 最大回撤 | `-3.28%` |
| 交易次数 | `9` |
| Profit Factor | `0.90` |

同区间不加 4H 过滤时，收益 `-2.49%`，交易 `17` 笔，Profit Factor `0.81`。所以 4H 过滤减少了亏损，但没有让 2026 年前 5 个月转正。

`2025-05-14 ~ 2026-05-14`，两种入场 + 4H 过滤：

| 指标 | 结果 |
| --- | ---: |
| 收益 | `8.52%` |
| Buy & Hold | `-12.00%` |
| Sharpe | `1.27` |
| 最大回撤 | `-4.63%` |
| 交易次数 | `27` |
| Profit Factor | `2.14` |

同区间不加 4H 过滤时，收益 `1.82%`，交易 `42` 笔，Profit Factor `1.13`。这说明最近一年里，4H 过滤明显提升了交易质量。

目前结论是：

- `trend_holding_v3` 的收益确实依赖少数右尾盈利单。
- 放宽 ATR 跟踪止损到 `3.0` 有助于持仓更久。
- 单独突破入场不强，回踩重站更值得保留。
- 4H 过滤有效，尤其能减少低质量 1H 信号。
- 2026 年前 5 个月仍然亏损，说明策略还没有跨行情稳定。
- 下一步不该只继续优化 ETH，而应该做多交易对验证。

## 为什么趋势持仓比双均线更值得学

双均线只解决一个问题：

```text
趋势方向可能变了没有？
```

`trend_holding_v3` 解决的是一组更完整的问题：

```text
趋势是否存在？
价格是否突破？
波动是否适合？
趋势是否还活着？
亏损到哪里退出？
盈利能不能继续拿？
```

这才是趋势策略真正困难的地方。

趋势策略不追求每笔都对。它经常会出现：

```text
小亏
小亏
小赚
小亏
大赚
```

只要大赚足够大，就可以覆盖前面的试错成本。双均线可以让你理解趋势方向，但趋势持仓能让你理解右尾收益。

## 今天学到什么

第一，策略失败后不要只在原方向上继续加指标。

Day 3 的问题不是缺一个更好的超卖指标，而是均值回归本身在跨资产上不稳定。这个时候应该换收益来源，而不是继续堆过滤条件。

第二，趋势策略的核心不是胜率。

均值回归常常追求较高胜率，趋势策略追求的是盈亏比和右尾捕捉能力。一个趋势策略胜率不高也可能赚钱。

第三，出场比入场更重要。

趋势持仓最怕两个问题：亏损单不止损，盈利单太早卖。ATR 跟踪止损、Donchian 下轨和结构破坏，都是为了解决这个问题。

第四，成本仍然是硬约束。

即使趋势策略比均值回归更有空间，如果交易太频繁或止损太近，手续费和滑点仍然会吞掉优势。

## Day 4 结论

Day 4 不应该停留在“双均线金叉买、死叉卖”。双均线适合作为对照组，但真正值得学习的是趋势持仓框架。

今天最重要的一句话：

> 加密货币策略不能只问“这次会不会反弹”，还要问“如果真正的大趋势来了，我能不能识别它、进入它，并拿得住它”。
