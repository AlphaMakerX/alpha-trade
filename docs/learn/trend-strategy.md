# 趋势策略总结：trend_holding_v3

> 本文以 `strategies/trend/trend_holding_v3.py` 为对象，总结趋势持仓策略的思维框架、指标分工、入场与出场逻辑。配套实证见 `docs/learn/day4-trend-holding.md`。

## 一、核心思想

趋势策略和均值回归赚的是**两种相反结构**的钱：

| | 均值回归 | 趋势持仓 |
| --- | --- | --- |
| 赚什么 | 短期修复 / 反弹 | 右尾大行情 |
| 胜率 | 高 | 低也没关系 |
| 怕什么 | 单边下跌 | 趋势中途被洗出去 |
| 胜负手 | 入场（进得准） | **出场（拿得住）** |

加密货币的收益高度集中在少数强趋势阶段（右尾）。趋势策略的目标不是提高胜率，而是：

> 接受多次小亏，但必须抓住少数大行情——**少数大盈利单覆盖多数小亏损。**

## 二、把趋势交易拆成四个问题

`trend_holding_v3` 不是简单的金叉死叉，而是回答四个独立问题：

```text
1. 有没有趋势?      → 价格 > 长期EMA 且 长期EMA向上
2. 什么时候进?      → 突破Donchian高点 / 回踩短EMA重新站上
3. 波动适不适合?    → ATR分位数不太低也不太高
4. 趋势死了没?      → 跌破Donchian下轨 / 结构破坏 / ATR追踪止损
```

双均线只能回答问题 1 的一部分，其余三个都答不了，所以它只能作对照组，不能作主线。

## 三、指标分工

每个指标只负责一件事：

| 指标 | 参数 | 职责 |
| --- | --- | --- |
| 长期 EMA | `trend_period=150` | 定方向：价格在其上方且其向上才考虑做多 |
| 短 EMA | `pullback_period=55` | 回踩重站入场锚点 + 结构破坏判断 |
| Donchian 高点 | `breakout_period=120` | 突破入场（`shift(1)` 防未来函数） |
| Donchian 低点 | `exit_period=55` | 结构性出场位 |
| ATR | `atr_period=20` | 初始止损距离、仓位计算、追踪止损 |
| ATR 分位数 | `atr_percentile_period=200` | 过滤死水行情和极端过热波动 |
| 高周期过滤 | 4H EMA200 | 用 4H 趋势过滤低质量 1H 信号（可选） |

## 四、入场逻辑

入场是**多条件的交集**（`next()` 第 217 行），全部满足才开仓：

```text
入场 = 趋势确认 + 高周期确认 + 波动允许 + 入场信号 + 风控允许
```

入场信号有两种（满足其一）：

**突破入场**（`use_breakout_entry`）

```text
价格 > Donchian高点(前120根)
```

**回踩重站**（`use_pullback_entry`，默认开启）

```text
上一根收盘 <= 短EMA       # 短暂回到短EMA附近
当前价 > 短EMA            # 重新站上
当前价 > 上一根K线高点     # 突破上一根高点确认转强
```

回踩重站买的不是"最低点"，而是"趋势回调后重新转强的确认点"。实证上它的交易质量明显强于纯突破入场。

开仓时同时设初始止损，并参与仓位计算：

```python
sl = price - atr_multiplier * atr   # 第223行，3倍ATR
self.buy_with_risk(price, sl)
```

## 五、出场逻辑（策略核心）

出场分**两层**，每根 K 线按顺序执行，任一触发即平仓（`next()` 第 198 行起）：

```text
每根K线:
1. 先跑通用风控 apply_risk_management(atr)   ← 第一层
2. 若仍持仓 → 检查策略趋势退出 _exit_signal   ← 第二层
```

### 第一层：通用风控（来自 `init_risk()`）

在策略信号之前执行，负责四类硬性平仓：

- **初始止损**：`3 × ATR`
- **ATR 追踪止损**：`trailing_atr_multiplier=3.0`，止损线随价格上抬、不下移——**拿住盈利单的核心**
- **最大回撤**限制
- **时间止损**：`max_holding_bars`（默认 0 = 不启用）

### 第二层：策略趋势退出（`_exit_signal`，第 181 行）

两个条件满足其一即卖：

```python
# 1. 通道跌破：跌破近期结构低点，反应快，不等均线确认
channel_break = price < donchian_low

# 2. 结构破坏：跌破短EMA 且 长期EMA已转头向下（双条件，更严格）
structure_broken = price < pullback_ema and trend_now < trend_then

return channel_break or structure_broken
```

### 完整出场清单

共 **5 个触发器**，先到先平：

| 触发器 | 来源 | 性质 |
| --- | --- | --- |
| 初始止损（3×ATR） | 风控层 | 保护性 |
| **ATR 追踪止损（3×ATR）** | 风控层 | **核心，拿住并保护利润** |
| 最大回撤 | 风控层 | 账户级保护 |
| 通道跌破（Donchian 下轨） | 策略层 | 结构性退出，反应快 |
| 结构破坏（破短 EMA + 长 EMA 向下） | 策略层 | 趋势确认性退出 |

> 关键认知：入场只是一行交集判断，出场却铺了 5 个触发器、分两层。**追踪止损决定大盈利单能跑多远，是趋势策略真正的胜负手。**

## 六、参数调优要点

`optimize_params()` 暴露的核心研究参数：

```python
trend_period:       [150, 200, 300]
breakout_period:    [55, 80, 120]
pullback_period:    [21, 34, 55]
exit_period:        [34, 55, 80]
atr_multiplier:     [2.5, 3.0, 3.5]
min_atr_percentile: [0.10, 0.20, 0.30]
```

实证经验：

- **放宽追踪止损（2.0→3.0）**：更能拿住趋势，收益和 PF 小升，代价是回撤变大。
- **回踩重站 > 突破入场**：在 ETH 上回踩重站收益/Sharpe/PF 全面更好。
- **4H 过滤**：作用不是提高收益，而是减少低质量信号（交易次数↓，PF↑）。

## 七、实盘准入标准

正收益远远不够，缺以下证据就不能实盘：

```text
1. 多交易对验证      —— 不止单币种有效
2. 参数邻域稳定性    —— 不是只有一个点有效（否则过拟合）
3. Walk-forward / 样本外验证
4. 成本敏感度        —— commission 提到 0.20% 不能失效
```

`trend_holding_v3` 当前结论：**有研究价值，尚无实盘资格。**

## 一句话总结

> 趋势策略 = 识别趋势 → 在回调转强处入场 → 用追踪止损拿住大行情。
> 每个指标只负责框架里的一个问题；入场只要"不太差"，真正的钱在"拿得住"。
