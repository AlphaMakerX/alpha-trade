# 当前最好的策略：趋势持仓 trend_holding_v3

> 目前主线候选。**有研究价值，但还没有实盘资格**（结论与准入见 `../architecture/strategy-status.md`）。

## 它赚什么钱

加密货币的大部分收益集中在少数强趋势阶段（右尾）。这个策略不追求高胜率，而是：

> 接受多次小亏，抓住少数大行情 —— **少数大盈利单覆盖多数小亏损。**

和均值回归正好相反：均值回归赚短期反弹、胜率高但怕单边；趋势持仓赚大行情、胜率低没关系，**胜负手在出场能不能拿住**。

## 它怎么想：四个问题

不是简单的均线金叉死叉，而是依次回答四个问题：

| 问题 | 判断 |
| --- | --- |
| 1. 有没有趋势？ | 价格在长期均线上方，且长期均线向上 |
| 2. 什么时候进？ | 突破前期高点，**或**回调到短均线后重新站上 |
| 3. 波动合不合适？ | 波动不能太低（没延续）也不能太高（追在情绪极端） |
| 4. 趋势死了没？ | 跌破近期结构低点、或结构破坏、或跟踪止损触发 |

> 「回踩重站」买的不是最低点，而是**趋势回调后重新转强的确认点**。实证上它的交易质量明显强于纯突破入场。

## 出场是核心

入场只是「不太差」就行，真正决定收益的是**拿得住**：用跟踪止损让盈利单继续跑，同时在趋势真破坏时退出。放宽跟踪止损能拿住更大趋势（收益升、回撤也变大），这是趋势策略的固有取舍。

## 实证要点（ETH/USDT 1h）

- 全区间收益约 15%，2023/24/25 年均为正，2026 前几个月仍亏。
- 回踩重站 > 纯突破入场。
- 加 4h 大趋势过滤：作用是**减少低质量信号**（交易数↓、单笔质量↑），不是单纯提收益。
- 多交易对里只有 ETH、SOL 明确为正 → 跨币种稳定性还不够。

## 一句话

> 识别趋势 → 在回调转强处入场 → 用跟踪止损拿住大行情。进场只要不太差，钱在「拿得住」。
