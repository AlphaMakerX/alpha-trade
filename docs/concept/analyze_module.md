# Analyze 看盘模块

## 一句话原理

> 从 K 线算出几个公认技术指标，每个指标投一票（看多 +1 / 看空 −1 / 中立 0），加总：正得多「偏多」、负得多「偏空」、不上不下「震荡」。**结论由固定规则算出，AI 只把它讲成人话，不参与判断。**

同样的数据永远得到同样的结论 —— 可复现、可回测、可单测。

## 流程

```text
数据库K线 → 算指标快照 → 打分定方向 → AI解读 → 存md报告
           snapshot.py    bias.py     analyst.py
```

## 算哪些指标

均线(MA20/MA50)、RSI(14)、MACD(12,26,9)、布林带(20,2)、ATR(14)、成交量/均量(20)、4h EMA200（大趋势）、近期高低点（压力/支撑）。

> 指标在**全量历史序列**上计算（保证 MA200/EMA200 准确），只取**最后一根**作为当前快照。

## 怎么打分（核心）

4 个投票项，每个投 `+1 / −1 / 0`：

| 投票项 | +1 看多 | −1 看空 |
| --- | --- | --- |
| 均线排列 | 价 > MA20 > MA50 | 价 < MA20 < MA50 |
| 4h 大趋势 | 4h 收盘 > EMA200 | 4h 收盘 < EMA200 |
| MACD | DIF > DEA 且柱 > 0 | DIF < DEA 且柱 < 0 |
| RSI | 50 ≤ RSI < 70 | 30 < RSI ≤ 50 |

加总定档：**≥ +2 偏多 / ≤ −2 偏空 / −1~+1 震荡**。逻辑：至少两个指标同向且没被抵消，才敢表态，否则判震荡。

> RSI 极值（≥70 超买 / ≤30 超卖）投 0 票，转为风险提示 —— 涨太猛往往意味着随时回调，当方向信号会误导。

## 风险提示（只警示，不影响方向）

RSI 超买/超卖、触布林上/下轨、1h 与 4h 趋势背离、缩量（量 < 均量 ×70%）。

## 重要：它是描述工具，不是交易信号

这套打分描述的是**当前状态偏多还是偏空**，不是对未来价格的预测。「偏多」只意味着此刻多指标共振向上，不等于接下来一定涨。

**有回测证据**（`bias-eval` 在 ETH 3 年上验证，每根 K 线算倾向再统计其后真实涨跌）：

- 「偏多」之后上涨概率不到 50%，方向预测力很弱，多半只是吃了 ETH 本身的上涨惯性。
- 「偏空」之后价格平均还涨，「真跌」命中率仅 45–48%，作为做空信号基本是反的（超卖时往往被抄底）。

> 所以别把 `bias` 当交易信号，更别为「抓某次大跌」去调打分逻辑（那是对单一样本过拟合）。要做能赚钱的信号走策略 + 回测那条线。
