# 策略研究方法论（心法）

> 从 `docs/learn` 提炼的可复用判断框架。一句话主线：
> **先证明策略为什么应该赚钱 → 再证明它在数据上真的赚钱 → 最后证明它在成本和坏行情下还能活下来。**

## 一、先找收益来源

策略盈利必须来自某种市场现象，否则只是噪音：

| 来源 | 赚什么钱 |
| --- | --- |
| 趋势 | 价格进入强趋势会持续一段时间（右尾） |
| 均值回归 | 价格短期偏离太远后回到合理区间 |
| 波动扩张 | 低波动后放量突破，后续延续 |
| 风险补偿 | 承担别人不愿承担的波动/回撤/流动性风险 |

「金叉买、死叉卖」但说不清为什么该赚钱 → 大概率是噪音。

## 二、最小完整策略的五要素

最小可验证策略不需复杂，但必须完整，缺一项回测就可能失真：

1. 入场：什么条件买入？
2. 出场：什么条件卖出？
3. 止损：判断错了亏到哪退出？
4. 仓位：每次最多亏账户多少？
5. 过滤：哪些环境不交易？

> 尤其：**没有止损和仓位管理的回测，看起来赚钱也不能信。**

## 三、判断有没有价值（不要只看收益率）

| 检查项 | 最低标准 |
| --- | --- |
| 全区间收益 | 正，且不明显跑输空仓基准 |
| 年度稳定 | 不是只靠某一年赚钱 |
| 季度集中度 | 不是只靠某一个季度赚钱 |
| 最大回撤 | 可承受、可解释 |
| Profit Factor | 基础成本下 > 1.1 |
| Sharpe | 为正 |
| 交易次数 | 样本足够，至少约 30 笔；低频要说明原因 |
| 成本压力 | commission/slippage 提高后不能直接失效 |

**核心教训**：「跑通」≠「可实盘」。低回撤可能只是几乎不交易；交易太少时 PF/胜率/Sharpe 全都会误导。

## 四、趋势 vs 均值回归（两种相反结构的钱）

| | 均值回归 | 趋势持仓 |
| --- | --- | --- |
| 赚什么 | 短期修复 / 反弹 | 右尾大行情 |
| 胜率 | 高 | 低也没关系 |
| 怕什么 | 单边下跌 | 趋势中途被洗出去 |
| 胜负手 | 入场（进得准） | **出场（拿得住）** |

加密收益高度集中在少数强趋势阶段，所以趋势策略的目标不是提高胜率，而是
**接受多次小亏，抓住少数大行情**。判断趋势策略要拆成四问：
有没有趋势 / 何时进 / 波动合不合适 / 趋势死没死。
（实现见 `strategies/trend/trend_holding_v3.py`，业务总结见 `best-strategy.md`。）

## 五、正确的研究顺序

```text
写清策略假设 → 实现最小完整版 → 全区间回测 → 年度/季度切片
→ 手续费/滑点压力测试 → 看失败阶段并解释为什么亏
→ 只针对失败原因做小改动 → 重复验证
```

## 六、不要做的事

- 不要先学一堆指标再想怎么用——指标是信号，不是收益来源。
- 不要一开始就上机器学习 / 复杂多因子。
- 不要因一次漂亮回测就重仓，先怀疑过拟合。
- 不要跳过成本压力测试。
- **优化必须对应失败原因**：结构性问题靠加判断（过滤）解决，不是盲目扩大参数网格。
