# 核心概念总览

纯业务视角，讲清「是什么、为什么这么做」，不深入代码。

| 文档 | 内容 |
| --- | --- |
| `strategy-research.md` | 怎么判断一个策略值不值得做（心法 + 检查清单） |
| `best-strategy.md` | 当前最好的策略 trend_holding_v3（业务视角总结） |
| `strategies-learned.md` | 学过的几种策略小结（一策一卡片） |
| `analyze_module.md` | `analyze` 看盘模块：用固定规则给指标投票定方向，AI 只翻译 |

> 一句话主线：先证明策略**为什么应该赚钱** → 再证明它**在数据上真的赚钱** → 最后证明它**在成本和坏行情下还能活下来**。
