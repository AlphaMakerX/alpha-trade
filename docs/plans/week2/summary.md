# Week 2 总结（策略学习）

> 任务清单见 `tasks.md`。

## 关键收获

- **低回撤 ≠ 好策略**：rsi_revert 回撤小只是因为几乎不交易；交易太少时 PF/胜率/Sharpe 都没意义。
- **优化必须对应失败原因**，不是盲目扩大参数网格；结构性问题靠加过滤而非调参解决。
- **均值回归 vs 趋势**赚的是两种相反结构的钱：均值回归吃短期修复、怕单边；趋势吃右尾、怕中途被洗出。加密收益高度集中在少数强趋势，趋势策略的胜负手在**出场能不能拿住**。
- `trend_holding_v3` 把趋势交易拆成四问：有没有趋势 / 何时进 / 波动合不合适 / 趋势死没死。

## trend_holding_v3 实证要点（ETH/USDT 1h）

- 基础版全区间收益 15.24%，PF 1.14，202 笔，2023/24/25 均为正，2026 前 5 月亏损。
- 放宽 ATR 追踪止损 2.0→3.0：更能拿住趋势，收益/PF 小升，回撤变大。
- **回踩重站 > 突破入场**（ETH 上收益/Sharpe/PF 全面更好）。
- 4H 过滤：作用是减少低质量信号（交易数↓、PF↑），不是单纯提收益。
- 多交易对仅 ETH、SOL 明确为正，BNB/ADA/XRP 不通过。
