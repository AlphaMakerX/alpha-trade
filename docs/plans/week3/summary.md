# Week 3 计划（学习并验证 Momentum 因子）

> 任务清单见 `tasks.md`。

主线：把 Momentum 当作一个**因子**来验证——先问它有没有预测力，再谈能不能赚钱。
不是直接写策略调参，而是用统一口径（forward-return / IC）判断因子真伪。

## 范围约定

- **标的 / 周期**：ETH/USDT，1h（复用现有主线数据）。
- **因子定义**：时序动量，`mom_N(t) = close_t / close_{t-N} - 1`（过去 N 根收益）。
- **回看窗口**：5/10/20/30/60「日」，按 1h 映射为 120/240/480/720/1440 根。
- **验证口径**：复用 `analysis/bias_eval.py` 模式——每根 K 线算因子值 → 统计其后 N 根真实涨跌，
  与无条件 baseline（平均涨幅 / 上涨概率）对比，再看分位分层收益单调性与 IC。

## 逐日计划

- **Day 1**：理解 Momentum 理论基础——时序 vs 截面动量、加密为何动量强、动量的失效场景（反转 / 拥挤 / 成本）。
- **Day 2**：从零实现 Momentum 计算，并搭实验框架（复用取数，仿 bias_eval 写因子评估），不写策略。
- **Day 3**：对 ETH 1h 测多个 lookback（5/10/20/30/60 日），看参数稳定性——IC / 分层收益是否随窗口平滑，而非忽正忽负。
- **Day 4**：判断是否真有预测力（不看回测收益）——forward-return、分位分层单调性、IC 均值 / IR、对比 baseline、分年稳定性。
- **Day 5**：加入 commission + slippage，把因子转成最简多 / 多空信号回测，验证扣成本后是否仍有效；总结优缺点与失效条件。

## 成功标准

- 因子评估可复现、可单测，结论与 baseline 有明确对比，不靠单一回测收益下判断。
- 能明确回答：Momentum 在 ETH 1h 上**有没有**预测力、**哪个窗口**最稳、**扣成本后**是否还成立。
