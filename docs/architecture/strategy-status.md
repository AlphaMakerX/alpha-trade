# 策略现状与实盘准入

> 反映 `docs/learn` 验证后的最新结论。流程主线见 `architecture.md`，方法论见 `concept/strategy-research.md`。

## 策略清单与最新结论

| 策略 | 类型 | 最新验证结论 |
| --- | --- | --- |
| `ma_cross` | 双均线趋势 | 旧基线。高年化候选 walk-forward 失败（训练段亏损），不直接实盘 |
| `rsi_revert` | RSI 均值回归 | 失败：条件太严，跨币种跨区间交易样本不足 |
| `bollinger_revert` | 布林 + RSI + 低 ADX | 失败：多交易对全区间亏损、Sharpe 全负，非好独立策略 |
| `trend_breakout` | Donchian 突破 | 趋势原型，未形成正期望 |
| `regime_switch` | 趋势/震荡状态切换 | 低回撤、初步正收益，但边际薄、高成本下失效 |
| **`trend_holding_v3`** | 趋势右尾持仓 | **当前主线**：有研究价值，尚无实盘资格 |

## 当前主线：trend_holding_v3

把趋势交易拆成四问：有没有趋势 / 何时进 / 波动合不合适 / 趋势死没死。
- ETH/USDT 1h 全区间收益 15.24%，PF 1.14，202 笔；2023/24/25 为正，2026 前 5 月亏损。
- 经验：放宽 ATR 追踪止损更能拿住趋势；回踩重站入场质量优于纯突破；4H 过滤减少低质量信号。
- 多交易对仅 ETH、SOL 明确为正，BNB/ADA/XRP 不通过 → 跨币种稳定性不足。

## 实盘准入标准（缺一不可）

```text
1. 数据质量 OK（缺失/重复/异常/非正成交量有明确处理口径）
2. 全区间正收益，且不明显跑输空仓基准
3. 交易次数足够（≥ 30；低频策略须说明原因）
4. Profit Factor 基础成本 > 1.1，高成本不破 1.0
5. Sharpe 样本外为正
6. 最大回撤可解释、与收益目标匹配
7. 分段稳定：不靠单一季度/单一窗口赚钱
8. 多资产：≥3 个交易对中 ≥2 个不失效
9. 多周期：≥2 个周期中 ≥1 个稳定、另一个不反向失效
10. 实盘一致性：同一根已闭合 K 线，signal 与回测信号一致
```

> 不满足 → 只能继续研究，不能接入 `main.py signal`。

## 距离实盘还缺的证据（trend_holding_v3）

1. 4H 过滤版本的多交易对验证。
2. 参数邻域稳定性（不能只有单一参数点有效）。
3. Walk-forward / 样本外验证。
4. 降低成本敏感度（commission 提到 0.20% 当前会失效）。
5. `signal` 接入已验证参数 + 只用已闭合 K 线。
